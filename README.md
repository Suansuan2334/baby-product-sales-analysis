# baby-product-sales-analysis
# 母婴产品销售分析（Power BI + MySQL）

## 项目背景
分析母婴品类销售情况，定位核心品类、监控月度波动、评估品牌集中度

## 数据来源
公开数据集，约1.2万条订单数据

## 工具
- MySQL：数据清洗
- Power BI：数据建模与可视化
- DAX：度量值开发

## 核心指标
- 总成交量
- 月度环比
- 品牌集中度（CR3/CR5）

## 看板页面（6个）
1. 销量分析页
2. 趋势分析页
3. 同环比分析页
4. 品牌集中度页
5. 价格带分析页
6. 总计指标卡

## 核心结论
- TOP3品类贡献超50%成交量
- 2020年3月环比+109%，2021年1月环比-26%
- 头部品牌效应明显
