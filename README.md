# 母婴产品销售分析（Power BI）

## 项目背景
分析母婴品类销售情况，定位核心品类、监控月度波动、评估品牌集中度

## 数据来源
公开数据集（淘宝母婴订单数据），约1.2万条记录

## 工具
- Power BI / Power Query：数据清洗与建模
- DAX：度量值开发

## 数据清洗（Power Query）
- 过滤空值和异常值（销售额≤0的订单）
- 合并品牌表和订单表
- 转换日期字段格式

## 核心指标
- 总成交量
- 月度环比
- 品牌集中度（CR3/CR5）

## 看板页面（6个）
1. 销量分析页（品类分布）
2. 趋势分析页（月度趋势）
3. 同环比分析页（波动监控）
4. 品牌集中度页（排名+累计百分比）
5. 价格带分析页（售价区间）
6. 总计指标卡

## 核心结论
- TOP3品类（孕妇装、哺乳文胸、家居服）贡献超50%成交量
- 2020年3月环比暴涨109%，2021年1月环比暴跌26%
- 头部品牌效应明显，建议运营资源向TOP品牌倾斜
